Welcome, and thank you for helping us review RBioBench.

This page is a workspace for researchers and practitioners who can help us examine the quality of individual benchmark tasks. You do not need to review the full collection—even a careful review of one task is valuable.

We especially welcome experience in bioinformatics, Bioconductor, clinical programming, pharmaverse or CDISC workflows, R, and the evaluation of coding agents.

Abstract

Biomedical research increasingly relies on AI-generated analysis code, but existing benchmarks rarely test whether biomedical R programs execute and produce correct artifacts. We introduce RBioBench, an execution-graded benchmark of 405 tasks covering 208 Bioinformatics workflows grounded in Bioconductor and 197 Clinical Study workflows grounded in pharmaverse and CDISC practice. Each task combines a natural-language instruction, structured inputs, reference outputs and containerized grading. Candidate programs are evaluated through execution and artifact comparison rather than textual similarity. Reliability remains limited across all evaluated system families. The strongest Clinical Study result reaches 58.4%, whereas no system exceeds 40% on Bioinformatics. Failures concentrate in runtime behavior, package APIs, biomedical data structures and output schemas rather than syntax alone. In a 31-task substudy, curated function-reference lists improve accuracy for both coding agents at equal or lower token cost, while open-ended web documentation does not. RBioBench provides a reproducible testbed for measuring and improving AI systems intended for biomedical R programming.

Why your review matters

Biomedical R programming depends on specialized packages, data structures, terminology, and output conventions. An evaluator can check whether code runs and whether its artifacts match a reference, but it cannot by itself determine whether a task is scientifically meaningful, clearly specified, realistic, or fair.

RBioBench turns biomedical analysis workflows into executable task contracts: a natural-language request, structured inputs, expected artifacts, and a containerized evaluator. We created the collection to test whether coding agents can do more than produce plausible-looking R code—whether they can complete domain-specific work correctly.

This review page exists so domain experts can inspect those contracts directly. Your feedback will help us identify ambiguous wording, inappropriate package use, unrealistic inputs, incomplete expected outputs, and evaluator assumptions that should be corrected.

How to review a task

  1. Choose a task. Start with one of the runnable tasks, or search the full collection by package or topic.
  2. Inspect the task contract. Read the request, inputs, and expected deliverables. For runnable tasks, you may also open the task-specific Colab notebook.
  3. Send a short assessment. Mark it as looking good, needing a change, or having a technical issue, and tell us what you noticed.

What should I look for?

  • Scientific relevance
  • Clarity and completeness
  • Correct package and API use
  • Realistic inputs
  • Appropriate expected artifacts
  • Fair evaluation criteria
  • Missing assumptions or edge cases
  • Reproducibility problems

What happens to my feedback?

Submissions are recorded in the project’s private review sheet. The RBioBench team will examine them and use them to prioritize corrections to task wording, fixtures, expected artifacts, and evaluation logic.

Thank you for contributing your time and domain expertise. Careful task review is essential to making RBioBench useful and trustworthy.
